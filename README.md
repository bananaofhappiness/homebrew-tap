# bananaofhappiness/homebrew-tap

Homebrew tap for [Soundscope](https://github.com/bananaofhappiness/soundscope) — a TUI for real-time analysis of audio files, system audio, and microphone input.

## Installation

```sh
brew install bananaofhappiness/tap/soundscope
```

Or tap first, then install:

```sh
brew tap bananaofhappiness/tap
brew install soundscope
```

## Notes

- The formula installs pre-built binaries published on the
  [Soundscope releases page](https://github.com/bananaofhappiness/soundscope/releases).
- macOS (Apple Silicon and Intel) and Linux (x86_64 and arm64, glibc-based) are supported.
- Linux binaries are built on Ubuntu 24.04 and require a reasonably recent glibc (2.39+).
- The formula is regenerated automatically by the `Update Homebrew tap` workflow in the
  main repository every time a release is published — no manual updates needed.
